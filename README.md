# Juego del Ahorcado en C++

Ahorcado para la terminal, con palabras al azar.

`ahorcado_jairo.cpp`: categorías, dificultad, dibujo del ahorcado, letras usadas, pistas, adivinar la palabra completa, puntaje y estadísticas.

## Compilar y jugar

```
g++ ahorcado_jairo.cpp -o ahorcado_jairo
./ahorcado_jairo
```
