# Juego del Ahorcado en C++

Dos versiones del ahorcado para la terminal, con palabras al azar.

| Archivo | Versión |
| --- | --- |
| `ahorcado_martin.cpp` | Sencilla: 10 palabras, 6 intentos, letra por letra. |
| `ahorcado_jairo.cpp` | Avanzada: categorías, dificultad, dibujo del ahorcado, letras usadas, pistas, adivinar la palabra completa, puntaje y estadísticas. |

## Compilar y jugar

```
g++ ahorcado_martin.cpp -o ahorcado_martin
./ahorcado_martin

g++ ahorcado_jairo.cpp -o ahorcado_jairo
./ahorcado_jairo
```
